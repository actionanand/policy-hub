# LocalTell Support

For LocalTell support, email **anand.official.in@gmail.com**.

Include the app version, Android version, device model, and safe reproduction steps. Do not email cell identifiers, location details, or Journey history unless they are necessary for the issue and you are comfortable sharing them.

## Common help

- **No locality or Easy location:** grant the requested location permission and ensure Android's system Location switch is enabled. LocalTell first uses a short on-device GPS fix to resolve a Home locality or when you choose **Get my location**. If GPS cannot provide a sufficiently usable coordinate, you can choose **Use assisted location** and connect to Wi-Fi or mobile data. Journey requests periodic GPS fixes only while you have explicitly started it.
- **No offline data:** open **Offline data**, refresh the list, and download a pack for the area you need.
- **Journey will not start:** allow cell access and, on Android versions that require it, allow notifications for the foreground-service notification.
- **Wrong or unknown locality:** results depend on the available GPS or assisted location fix and installed geographic pack. Try again where the sky is more visible, then install or update the relevant offline pack.
- **Easy code will not resolve:** check every digit or character and try again. A LocalTell code is decoded on your device; it reproduces its encoded coordinate but does not improve the accuracy of the original GNSS fix.
