# Card Nest Support

For Card Nest support, email **anand.official.in@gmail.com**.

Include the Card Nest version, Android version, device model, a description of
the issue, and safe reproduction steps when possible.

Never email full card numbers, CVVs, application PINs, receipt images,
unredacted financial records, `.cnbak` files, or exported reports.

## Common help

- **Forgotten application PIN:** Card Nest does not store a recoverable PIN.
  Clearing Android app storage or reinstalling also removes local data; preserve
  a usable encrypted backup before doing so.
- **Biometric unlock unavailable:** unlock with the application PIN and confirm
  that Android has an enrolled supported biometric.
- **Backup restore fails:** select a Card Nest `.cnbak` file and enter the exact
  backup passphrase used when it was created.
- **Reminder missing:** enable Card Nest notifications and review Android battery
  and notification settings. Always verify due dates with the issuer.
- **Receipt capture fails:** grant camera permission for new photos or use the
  system photo picker for an existing image.
- **SMS Sync is unavailable or permission was denied:** SMS Sync is optional
  and available only on supported Android distributions. Start it from SMS
  Review or its sync control, then allow both Android SMS permissions if you
  want inbox-based review. You can revoke access in Android settings, turn the
  feature off at any time, or paste a financial SMS for local parsing without
  inbox permission.
- **Report export fails:** choose an available writable destination and retry.
