# Life Leaf Support

For Life Leaf support, email **anand.official.in@gmail.com**.

Include the app version, Android version, device model, a description of the issue, and safe reproduction steps. Do not email diary content, PINs, backup passphrases, attachments, or backup files.

## Common help

- **Forgotten PIN:** the PIN is not recoverable. Clearing app storage or reinstalling removes local data, so preserve a usable backup beforehand.
- **Biometric unlock unavailable:** first set an app PIN, then confirm Android has a supported enrolled biometric and biometric unlock is enabled in Life Leaf.
- **Reminder does not appear:** enable the reminder, grant notification permission, select the intended days and time, and confirm Android allows Life Leaf notifications. Battery optimization can delay delivery.
- **Backup restore fails:** select a valid `.lifeleaf` backup and, for an encrypted backup, enter the exact passphrase used when it was created.
- **An attachment cannot be opened:** confirm the source file still exists and Life Leaf can access the file you selected.
- **Shared content is missing:** review the draft opened from Android's share action and choose Save; incoming shared content is not saved automatically.
