# Vault Nest Support

For Vault Nest support, email **anand.official.in@gmail.com**.

Include the Vault Nest version, Android version, device model, a description of
the issue, and safe reproduction steps when possible.

Never email your master password, saved credentials, OTP secrets, backup codes,
intrusion-evidence images, `.vaultpack` files, or CSV exports. The developer
cannot recover or decrypt a vault.

## Common help

- **Lost master password:** Vault Nest has no recovery service. Restore a usable
  backup only if you know that backup's passphrase and original master password.
- **Biometric unlock unavailable:** unlock with the full master password, then
  review biometric settings. Enrollment changes can invalidate the device key.
- **Backup restore fails:** confirm that the selected file is a Vault Nest
  `.vaultpack` file and that the separate backup passphrase is correct.
- **Notifications unavailable:** grant notification permission in Android and
  retry the reminder or credential-copy action.
- **Camera evidence unavailable:** the feature requires Android, a front camera,
  explicit camera permission, and the setting to be enabled.
- **CSV export:** treat the file as readable sensitive information and delete it
  after importing it into the intended destination.
