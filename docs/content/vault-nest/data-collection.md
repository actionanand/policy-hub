# Vault Nest Data Collection

**Last reviewed:** August 1, 2026

## Data stored locally

Vault Nest stores the credentials, secure notes, identities, Wi-Fi information,
custom fields, labels, saved templates, preferences, and security settings you
provide. Sensitive vault-item contents are encrypted locally. Limited indexed
metadata, such as item type, status, expiry dates, and timestamps, remains
outside each encrypted payload.

Optional features may also store Android-Keystore-protected biometric unlock
material, encrypted intrusion-evidence photos, temporary encrypted notification
copy values, and notification schedules on the device.

## Data collected by the developer

The app has no account, developer cloud, analytics, advertising, crash
reporting, or tracking service. The developer does not receive vault contents,
keys, passwords, evidence images, preferences, or app-usage data.

If you email support, the developer receives the information you voluntarily
include in that message.

## Data sent to other services by your actions

- Optional website-icon retrieval requests the website address stored in an
  item and candidate image URLs. Website servers may receive the device IP
  address, requested URL, time, and user agent. Vault secrets are not included.
- Android receives notification content needed for optional expiry reminders.
- Copy and share actions place selected information into the system clipboard
  or pass it to an app you choose.
- A document or cloud provider you select can receive exported backup or CSV
  files.

## Permissions

Camera, notifications, biometrics, internet access, and selected-file access are
used only for their related features. Vault Nest does not require broad storage,
location, contacts, phone, or SMS access for the reviewed functionality.
