# Delete ARFlix Data

ARFlix has no developer-operated online user account or cloud profile.

## Remove local login information

Choose **Logout** to remove the locally stored user record and login hash. The
family-content preference remains on the device.

## Delete all local app data

Clear ARFlix storage in Android system settings or uninstall the app. In a
browser, clear the site's localStorage, cache, and site data.

## Delete saved images

Clearing app data or uninstalling does not remove posters or other images saved
to the Android media library. Delete those copies separately using the gallery
or file manager, including files under **Pictures/ARFlix** where applicable.

TMDb, Google, YouTube, IMDb, image services, and other external providers manage
their own request logs under their respective privacy policies. Because the
developer holds no ARFlix account data, emailing support cannot delete local or
third-party records.
