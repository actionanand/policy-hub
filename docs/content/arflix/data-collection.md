# ARFlix Data Collection

**Last reviewed:** August 1, 2026

## Data stored locally

ARFlix stores a local display name, successful-login password hash, and family
content preference in localStorage. This is a local content gate, not a cloud
account. The plain-text password is not stored or sent to an ARFlix server.

## Network data processing

- TMDb receives searches, filters, media or person identifiers, content-filter
  parameters, and normal connection metadata for discovery data and images.
- Google receives normal connection metadata when the public AR Collection
  spreadsheet is loaded.
- YouTube, IMDb, watch providers, image hosts, or `wsrv.nl` receive requested
  URLs and connection metadata when their features are used.

## Data collected by the developer

ARFlix has no developer-operated analytics, advertising, tracking, account, or
telemetry endpoint. The developer does not receive local preferences or search
history. Support email contains only what you choose to send.
