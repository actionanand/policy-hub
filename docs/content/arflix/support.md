# ARFlix Support

For ARFlix support, email **anand.official.in@gmail.com**.

Include the ARFlix version, Android or browser version, device model, a
description of the issue, and safe reproduction steps. Do not send passwords or
private account information used with external services.

## Common help

- **No movie data appears:** verify internet access and retry. TMDb or network
  restrictions may temporarily prevent requests.
- **A title, rating, image, or provider is missing:** ARFlix displays available
  third-party metadata and cannot guarantee completeness or current accuracy.
- **A trailer will not play:** open it directly in YouTube and check regional or
  account restrictions.
- **Image saving fails:** confirm the image is available and Android permits the
  app to create media-library images.
- **An ARFlix link opens in a browser:** install a compatible Android build and
  review Android's supported-link settings.
- **Family filtering is unexpected:** review the family toggle or log out to
  return to the default restricted view.
