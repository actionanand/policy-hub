# Link Deck Data Collection

**Last reviewed:** August 1, 2026

## Data stored locally

Link Deck stores profiles, folders, bookmark URLs and details, notes, tags,
favourites, archive and trash status, favicons, visit metadata, and preferences
in SQLite on Android or IndexedDB in a browser. A PIN is stored only as a salted
PBKDF2 verifier. Android handles biometric verification without giving Link
Deck biometric templates.

## Data collected by the developer

Link Deck has no account, developer cloud, analytics, advertising, crash
reporting, or tracking service. The developer does not receive the local
bookmark database or usage data. If you email support, the developer receives
only what you choose to include.

## Data processed outside local storage

- Google's favicon service receives a saved website hostname when its icon is
  requested.
- Google may receive normal connection metadata for favicon and font requests.
- Saved websites and the selected browser receive a URL when you open it.
- A file or sharing provider you choose receives backups or bookmark exports
  sent to it.
