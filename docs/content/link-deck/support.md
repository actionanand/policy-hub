# Link Deck Support

For Link Deck support, email **anand.official.in@gmail.com**.

Include the Link Deck version, Android or browser version, device model, a
description of the issue, and safe reproduction steps when possible. Do not
email PINs, private URLs, complete bookmark collections, or backup files.

## Common help

- **Forgotten PIN:** the PIN is not recoverable. Clearing app storage or
  reinstalling also removes local data; preserve a usable backup beforehand.
- **Biometric unlock unavailable:** use the app PIN and confirm that Android has
  a supported enrolled biometric.
- **Backup restore fails:** select a supported Link Deck backup and enter the
  exact passphrase used for an encrypted backup.
- **Browser import fails:** export bookmarks in Netscape Bookmark HTML format
  and review the import preview.
- **A favicon is missing:** the website or Google's favicon service may not
  provide one; the bookmark itself remains available.
- **A link will not open:** confirm it uses HTTP or HTTPS and try opening it
  directly in the system browser.
