# Delete Link Deck Data

Link Deck has no online account or developer-operated cloud database. Its app
data is stored on your device.

## Delete bookmarks

Move a bookmark to **Trash**, then open Trash and choose **Delete permanently**.
Items in Trash remain on the device until permanently deleted. You can also
restore them before deletion.

## Delete a profile

Open profile management and delete the profile. Link Deck lets you export the
profile first, move its content to another profile, or permanently delete the
profile and its content. The default profile cannot be deleted.

## Delete all local data

Clear Link Deck storage in Android system settings or uninstall the app. In a
browser, clear the site's IndexedDB/site data.

## Delete files outside the app

Clearing app data does not remove `.linkdeck`, JSON backup, or exported bookmark
HTML files saved or shared outside Link Deck. Delete those files separately
from every destination.

Because the developer does not hold Link Deck account data, emailing support
cannot delete records stored on your device.
