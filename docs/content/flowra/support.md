# Flowra Support

For Flowra support, email **anand.official.in@gmail.com**.

Include the Flowra version, Android or browser version, device model, a
description of the issue, and safe reproduction steps when possible.

Do not email menstrual records, health details, PINs, passwords, screenshots
containing sensitive information, or an unreviewed `.flowra` backup file.

## Common help

- **Data is missing after reinstalling or clearing storage:** Flowra has no
  cloud sync. Restore a password-protected backup that you created beforehand.
- **A backup will not open:** select a `.flowra` backup created by Flowra and use
  its exact password. Flowra cannot recover forgotten backup passwords.
- **Reminders do not appear:** enable reminders in Flowra, grant Android
  notification permission, confirm that a prediction exists, and check battery
  and notification settings for the app.
- **Biometric unlock is unavailable:** enroll a supported strong biometric in
  Android, unlock Flowra with the app PIN, and enable biometrics again. A change
  to enrolled biometrics can invalidate the saved Keystore key.
- **The app remains locked:** use the configured app PIN. Biometric unlock is an
  optional convenience and does not replace the PIN.
- **Browser records disappeared:** browser site-data clearing, private browsing,
  storage eviction, or changing browser/profile/origin can remove or isolate
  IndexedDB data. Restore a backup if available.
- **CSV or PDF is not where expected:** check the browser's Downloads location
  or the destination selected by the print/save dialog.

Flowra provides estimates rather than medical advice. For health concerns,
contact a qualified healthcare professional rather than sending medical details
to app support.
