# AR Tamizh Solai Support

For content questions, corrections, contribution enquiries, technical support, copyright concerns, accessibility issues, or privacy requests, email **anand.official.in@gmail.com** or use the website contact form.

When reporting a content issue, include the article URL, the passage concerned, a concise explanation, and reliable source references where possible. Do not send passwords, payment credentials, or unnecessary sensitive personal information.

## Common Help

- **A page is unavailable:** try the other deployment link, refresh the page, or clear a stale browser cache.
- **Search cannot find an article:** use fewer keywords or browse the archive; search only covers published content.
- **An embed does not load:** browser privacy settings, network filtering, regional restrictions, or the external provider may block it. Open the referenced provider directly if a source link is available.
- **A protected article will not unlock:** confirm that you have the publisher-provided password and that browser storage is available. Clear the site's stored data and try again if an expired record causes trouble.
- **You found a translation or attribution issue:** send the specific text, source edition, and supporting reference for review.
- **You need a contact submission deleted:** email the publisher with the approximate submission date, email address used, and inquiry purpose.
- **A donation has a payment problem:** contact the payment provider handling the transaction; AR Tamizh Solai does not process payment credentials or provider refunds.
