# Click2Chat Support

For Click2Chat support, email **anand.official.in@gmail.com**.

Include the app version, Android or browser version, device model, a description
of the issue, and safe reproduction steps. Do not email phone numbers,
messages, or clipboard contents.

## Common help

- **WhatsApp does not open:** install WhatsApp or WhatsApp Business and verify
  the complete international phone number.
- **The wrong country appears:** change the calling code or choose a country
  from the searchable picker. India is selected on first launch. Countries
  sharing one code preserve the selected country when possible. Use **Custom
  calling code** for an unlisted code.
- **Clipboard paste fails:** browser or Android privacy settings may block
  clipboard access. Type the number manually.
- **Theme does not match the device:** choose **System** in the appearance
  picker, then confirm the device theme has changed.
- **Remove saved preferences:** clear Click2Chat app storage, uninstall the app,
  or clear the browser site's storage.
