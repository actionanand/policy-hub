# Personix Support

For Personix support, email **anand.official.in@gmail.com**.

Include the Personix version, Android or browser version, device model, a description of the issue, and safe reproduction steps when possible.

Do not email medical records, personal identifiers, contact details, app PINs, backup passwords, or `.pxbackup` files.

## Common help

- **Forgotten app PIN:** Personix does not store a recoverable PIN. Clearing app storage or reinstalling also removes local data, so preserve a usable encrypted backup beforehand.
- **Biometric unlock unavailable:** unlock with the app PIN and confirm that Android has an enrolled supported biometric.
- **Backup restore fails:** select a valid Personix `.pxbackup` file and enter the exact backup password used to create it.
- **Preview metadata is missing:** confirm internet access and the relevant metadata setting. Browser metadata fetching remains off until you explicitly enable it.
