# Stillora Support

For Stillora support, email **anand.official.in@gmail.com**.

Include the Stillora version, Android version, device model, a description of
the issue, and safe reproduction steps when possible.

Do not email personal information or an unreviewed backup file.

## Common help

- **No sound:** check Android media volume, the in-app volume control, connected
  Bluetooth devices, and whether another app controls audio output.
- **A sound does not start:** pause playback, choose another atmosphere, and
  reopen Stillora if needed. Audio is bundled and does not require streaming.
- **Timer stops playback:** choose a new duration or **Continuous**, then start
  playback again.
- **Backup import fails:** select a valid Stillora JSON backup created by the
  app. Files larger than the supported backup limit or invalid JSON are rejected.
- **Settings missing after reinstalling:** import a backup saved before the app
  was removed. Stillora does not provide cloud sync.
