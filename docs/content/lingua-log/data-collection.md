# Lingua Log Data Collection

**Last reviewed:** August 1, 2026

## Entry data

Lingua Log reads configured Google Sheet rows containing identifiers, timestamps, source languages and sentences, transliterations, translations, formatted explanations, tables, resource references, and a protected flag. Google and the Sheet owner receive or control this content and standard request metadata.

## Local data

Android can cache up to 30 Sheet entries in unencrypted localStorage, including protected rows. The app also stores theme, local user name and password hash, and optional salted PIN-verifier and biometric preferences. Android performs biometric verification without exposing biometric templates to the app.

Lingua Log has no developer-operated advertising, analytics, or telemetry. The developer does not automatically receive device-local records.
