# AR Tamil Jathagam Data Collection

**Last reviewed:** August 1, 2026

## Data handled locally

The app processes names, parents' names, gender, birth date and time, place, coordinates, time zone, and optional sunrise settings to calculate astrology results. Up to ten profiles can be saved as unencrypted JSON in localStorage. Language, login session, cipher key, and author or PDF preferences can also be stored locally.

## External processing

Configured Google Sheet rows can contain an identifier, label, reversibly obfuscated birth details, and save time. Google receives normal request metadata. Online Panchanga providers receive a selected date, time, place, coordinates, and time-zone information as required by each service.

The app has no developer-operated advertising, analytics, or telemetry. The developer does not automatically receive device-local profiles or reports.
