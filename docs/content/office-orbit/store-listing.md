Office Orbit brings your work activity, delivery context, and career evidence into one focused personal workspace.

Use authenticated dashboards to review the records that matter without moving through separate work trackers and reports.

Work Logs and Reports

• Browse work logs in list or calendar views
• Filter entries by date, category, type, project, company, team, JIRA, and sprint
• Review comments, issues, work modes, and appraisal markers
• Export selected work-log ranges as readable PDF reports

JIRA and Sprint Context

• Review active, blocked, spillover, demo-pending, and appraisal JIRAs
• Open detailed ticket relationships and sprint history
• View active and historical sprints
• Compare capacity, allocated days, remaining days, leave, and holidays
• Review planned allocations and their related JIRAs

Releases, Feedback, and Links

• Track pending, confirmed, and unannounced release items
• Review components, versions, branches, dates, and related tickets
• Browse appraisal, improvement, follow-up, and negative feedback
• Keep active project and company work links within reach

Dashboard and Analytics

• See active work, recent logs, releases, feedback, and useful links together
• Review work-log trends and category or type breakdowns
• Monitor current sprint health and JIRA attention counts
• Refresh data when you need the latest source records

Device Security

• Protect the Android app with an optional 4-to-6-digit PIN
• Enable biometric unlock on supported Android devices
• Restore an active authenticated session securely on the device

Web and Android

Office Orbit is available in a browser and as an Android application distributed outside Google Play. The browser version is hosted on GitHub Pages.

Office Orbit contains no advertisements or developer-operated analytics. It requires authenticated access to the configured Office Orbit API and is intended only for users authorized to view the connected work records.
