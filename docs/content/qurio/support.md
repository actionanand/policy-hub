# Qurio Support

Email **anand.official.in@gmail.com** with the Qurio version, Android or browser version, device model, affected screen, and safe reproduction steps. Never send passwords, PINs, access tokens, full answer history, or unnecessary information about a child.

## Common help

- **Missing verification email:** check spam, confirm the address, and use resend.
- **Waiting for approval:** verify email, then refresh status; manual approval may be required.
- **Sign-in or reset failure:** check internet access and use the registered email.
- **Progress not synchronized:** remain signed in, reconnect, and refresh; recent data may remain cached locally.
- **Content not loading:** retry with a working connection because learning files come from GitHub.
- **No reminders:** select days, enable reminders, and allow Android notifications. Battery restrictions can affect timing.
- **PIN or biometric failure:** use the PIN. Clearing site or app storage resets local protection and local settings.
- **Deletion:** follow the Qurio Data Deletion page.

Install Qurio from Google Play or use the official GitHub Pages browser version.
